OpenRGB SDK Integration

LumenForge can explicitly import controllers exposed by a locally running OpenRGB SDK server. OpenRGB is optional, nothing is imported automatically, and LumenForge does not start or manage the OpenRGB process.

Removing an imported controller preserves its profiles and RGB configuration so they can be reused if the controller is imported again later.
